Демонстрация внешней сортировки данных

Посмотрите, как алгоритм внешней сортировки слиянием упорядочивает числа из текстового файла.

Введите свои числа, выберите размер части и запустите интерактивную демонстрацию.

1 Исходные данные

Каждое целое число должно быть на отдельной строке. Можно загрузить текстовый файл.

Для примера используется маленький размер части, чтобы этапы были хорошо видны.

2 Процесс сортировки

Алгоритм делит данные на части, сортирует их отдельно и затем сливает.

1
Разделение файла

Числа читаются небольшими частями, которые помещаются в оперативную память.

↓
2
Сортировка частей

Каждая часть сортируется отдельно и сохраняется как временный результат.

↓
3
Слияние

Отсортированные части объединяются в одну последовательность.

После запуска здесь появятся части, полученные из исходных данных.

3 Результат

Ожидание запуска. Нажмите «Запустить сортировку».

〈/〉 Код программы (Python)

Ниже приведён пример реализации, который можно сохранить как external_sort.py.

import heapq
import tempfile
import os


def external_sort(input_file, output_file, chunk_size=1000):
    temp_files = []

    try:
        # 1. Читаем и сортируем данные частями
        with open(input_file, "r", encoding="utf-8") as source:
            while True:
                chunk = []

                for _ in range(chunk_size):
                    line = source.readline()
                    if not line:
                        break
                    chunk.append(int(line.strip()))

                if not chunk:
                    break

                chunk.sort()

                temp = tempfile.NamedTemporaryFile(
                    mode="w", encoding="utf-8", delete=False
                )
                temp_files.append(temp.name)

                with temp:
                    for number in chunk:
                        temp.write(f"{number}\\n")

        # 2. Сливаем отсортированные части
        with open(output_file, "w", encoding="utf-8") as result:
            files = [open(name, "r", encoding="utf-8")
                     for name in temp_files]
            try:
                for number in heapq.merge(
                    *(map(int, f) for f in files)
                ):
                    result.write(f"{number}\\n")
            finally:
                for f in files:
                    f.close()

    finally:
        # 3. Удаляем временные файлы
        for name in temp_files:
            if os.path.exists(name):
                os.remove(name)


if __name__ == "__main__":
    external_sort("numbers.txt", "sorted_numbers.txt", 3)
    print("Сортировка завершена!")

💡 Как это работает?

Внешняя сортировка применяется, когда весь набор данных не помещается в оперативную память. Вместо загрузки целого файла программа обрабатывает небольшие части и использует диск для промежуточных результатов.

✦ Где применяется?

В базах данных, обработке серверных журналов, анализе больших данных, построении поисковых индексов и сортировке больших наборов записей.

Вывод

Внешняя сортировка слиянием позволяет упорядочивать большие объёмы данных, обрабатывая их частями. Сначала отдельные части сортируются, затем объединяются в общий результат. Такой метод помогает работать с файлами, которые не помещаются целиком в оперативную память.
