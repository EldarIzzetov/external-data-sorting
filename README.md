Инструкция по запуску сайта «Внешняя сортировка данных»
1. Описание
Сайт предназначен для демонстрации принципа работы внешней сортировки данных слиянием. Он позволяет вводить числа, выбирать размер части, запускать сортировку, просматривать результат и изучать пример кода на Python.
2. Требования
Для запуска сайта необходимы:
Компьютер или ноутбук.
Современный веб-браузер: Google Chrome, Microsoft Edge, Mozilla Firefox или другой.
Файл index.html.
Устанавливать Python и дополнительные библиотеки для запуска сайта не требуется.
3. Запуск сайта на компьютере
Скачайте файлы проекта из репозитория GitHub.
Найдите файл index.html в папке проекта.
Откройте файл двойным нажатием мыши.
Сайт запустится в браузере автоматически.
Также можно нажать на файл правой кнопкой мыши, выбрать «Открыть с помощью» и указать нужный браузер.
4. Запуск сайта через GitHub Pages
Если сайт опубликован на GitHub Pages:
Откройте ссылку на опубликованный сайт.
Дождитесь загрузки страницы.
Перейдите к разделу демонстрации сортировки.
Для публикации необходимо открыть репозиторий GitHub, перейти в Settings → Pages, выбрать источник Deploy from a branch, ветку main и папку /(root), затем нажать Save.
После публикации GitHub предоставит ссылку на сайт.
5. Как пользоваться сайтом
В поле «Исходные данные» введите целые числа, каждое с новой строки.
Укажите размер части — количество чисел, обрабатываемых за один этап.
Нажмите кнопку «Запустить сортировку».
Посмотрите, как программа разделяет числа на части и сортирует каждую часть.
Изучите итоговый результат в поле «Результат сортировки».
При необходимости нажмите «Скачать результат», чтобы сохранить отсортированные числа в файл sorted_numbers.txt.
Кнопка «Сбросить» возвращает исходный пример.
Также сайт содержит теоретическую информацию, пример реализации алгоритма на Python и описание областей применения внешней сортировки.

7. Возможные ошибки
Сайт не открывается: проверьте, что файл имеет расширение .html, а не .txt.
Сортировка не выполняется: убедитесь, что введены целые числа.
Файл не загружается: проверьте формат файла и наличие чисел в нём.
GitHub Pages не открывает сайт: проверьте настройки публикации и наличие файла index.html в корневой папке репозитория.
8. Заключение
Сайт позволяет наглядно изучить принцип внешней сортировки слиянием и продемонстрировать её работу на примере целых чисел. Для локального запуска достаточно открыть файл index.html в браузере. Для доступа через интернет можно использовать GitHub Pages.
Важно: сортировка в браузере является учебной демонстрацией алгоритма. Реальная обработка данных через временные файлы на диске реализована в отдельном примере программы на Python.
